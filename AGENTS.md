- The light/dark toggle has two states; never add "System" to it. A press flips what is shown, and clears storage when that matches the OS, per [Lea Verou](https://lea.verou.me/blog/2026/dark-mode-toggles/).
- The pixel backdrop is three layers: toys (`src/components/backdrop-toys/`) and `<emulated-canvas>` (`src/components/emulated-canvas/`) never import each other, and `<pixel-backdrop>` (`src/components/pixel-backdrop/`) imports both. `src/test/architecture.test.ts` holds this; never add to its `exceptions` or widen a layer's `imports` to make it pass without the owner's say, as that is the only thing keeping the layers apart.
- The limits in `scripts/budgets.mjs` are ratchets: lower one in the same commit when a change does less, and never raise one to make `pnpm budgets` pass without the owner's say, as each is an exact count with no margin to hide a regression in. The file's header has the full rule.
- A golden frame change must be deliberate: never update `src/components/backdrop-toys/__snapshots__/golden.test.ts.snap` just to make the test pass, and say in the commit what changed on screen and why, as the digests are what notices a refactor changing what a toy shows.
- Frame rates from a phone count only over HTTPS, so measure with `pnpm perf:device`: over plain HTTP, Safari runs the page's JavaScript without a JIT, which once read 48 fps where the real site holds 60.
- A toy is one file in `src/components/backdrop-toys/` plus its line in `TOYS` in its `index.ts`, and a shader pass one file in `src/components/emulated-canvas/shaders/` plus its line in `SHADERS`, as the tests and pages pick up the lists; a new toy also adds golden entries and script bytes, and a pass runs only where `src/components/pixel-backdrop/look.ts` writes its `data-*` knob.
- A theme is one entry in `DISPLAYS` in `src/components/pixel-backdrop/backdrop-displays.ts`: its scheme, the canvas's `base` and `ink`, the page's colours, and a `look` if it is a physical panel. The menus, the page's CSS, `theme-color`, the manifest and the backdrop all read that list, so never restate a theme's colours elsewhere; a new theme also adds golden entries and its per-frame budgets, as the tests and `pnpm budgets` say.
